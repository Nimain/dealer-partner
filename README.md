# dealer-partner

Holatractor Partner - Next-Generation AI & Telematics Operating System for Agricultural Dealerships and Tractor Fleet Owners.

## Features
- **Dealer OS & Inventory Management**: Interactive showroom, tractor parts inventory, automated service dispatch.
- **Fleet & Telematics Suite**: IoT telemetry, real-time geofence tracking, operator management.
- **Multilingual Support**: Dynamic Spanish / English localization.
- **Dealer Brochure Download**: Built-in PDF brochure generator and direct-download endpoint.
- **Automated Lead Management & Notifications**: Dual email alerts to dealership and operations teams, syncing with b2bholatractor backend.

## Tech Stack
- **Framework**: Next.js 16 (App Router & Turbopack)
- **Styling**: TailwindCSS & Framer Motion
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
